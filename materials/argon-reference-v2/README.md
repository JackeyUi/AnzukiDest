# Anzuki 角色參考素材 v2

此資料夾是供 Argon 生成動畫的新版參考素材。

- `anzuki-reference-v2.png`：高清透明背景全身 PNG。請下載原始檔後上傳給 Argon。
- `argon-prompts-zh-TW.md`：共同規格、六個基本動作與負面提示詞。

## 本版角色修正

1. 後髮只到腰身，髮尾約在束腰下緣附近。
2. 黑色短披肩覆蓋肩部。
3. 白色寬袖是獨立袖套，上緣與披肩之間露出上臂皮膚；不是與上衣連接的長袖。
4. 雙手空著，沒有法杖。

製作動畫時每次使用這張相同的參考圖，並先貼共同規格，再貼一個動作。工具若支援首尾幀，可使用相同站姿圖設定首尾幀。

這個資料夾提供參考圖與生成提示詞，動畫影片需另外生成。舊版六動作桌寵包仍採用先前角色設計，尚未依本版參考圖重製。
