# 第一批影片素材處理

三個 `original/*.mp4` 與使用者上傳的原檔逐位元相同，保留來源音訊、畫質及完整內容。

## 來源

| 原檔 | 視訊規格 | 用途 |
| --- | --- | --- |
| video2_loop_long.mp4 | 720×1280、24 fps、94 幀，約 3.917 秒 | 一般待機，全段使用 |
| video2_loop_short.mp4 | 720×1280、24 fps、60 幀，2.5 秒 | 備用待機，全段使用 |
| gemini_generated_video_1019414a.mp4 | 720×1280、24 fps、240 幀，視訊 10 秒 | 擷取兩段點擊動作；原檔音訊容器約 10.005 秒 |

## 擷取（結尾不包含該幀）

- click-bounce-1：第 6–59 幀，0.25–2.50 秒，54 幀，2.25 秒。
- click-bounce-2：第 72–127 幀，3.00–5.333333 秒，56 幀，2.333333 秒。

以原片的預備動作、彈起表情與回穩姿勢組成。腳底幾乎不離地，屬原地彈動，不是完整騰空跳躍；沒有用程式額外加入跳躍或放大縮小。

## 處理

1. 依幀號擷取，保留原始 24 fps，停用自動補重複幀。
2. 利用綠色相對紅／藍的差值建立柔邊 alpha；背景有編碼色差，並非完全純綠。
3. 依邊界估計綠幕色，修正邊緣顏色並去除綠色溢色，再做輕微的邊緣收縮以抑制壓縮綠邊。
4. 產生 `transparent-masters/` 的 720×1280 VP9-alpha WebM，保留原始畫幅與相對運動。
5. 產生 `../../pet/anzuki-animation/` 的 640×360 WebM：固定縮放至 158×280，再放到 x=241、y=50，站姿腳底約在 y=306。
6. 播放檔與透明母版皆移除音訊，點擊不突然發聲；原始影片保留音訊。

透明 WebM 需由支援 VP9 alpha 的瀏覽器／Electron 播放。部分播放器顯示黑底不代表 alpha 遺失。來源雜訊及生成影片本身的細微形變會保留，未宣稱逐幀手工修圖。

精確參數、來源 SHA-256 與擷取區間見 `manifest.json`。重製程式位於 `../../scripts/process-videos.py`。

桌寵格式與流程參考：https://github.com/PC2005-cloud/dsh-pet
