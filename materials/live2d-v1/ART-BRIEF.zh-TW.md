# 杏月 Anzuki：分層立繪與 Live2D 建模交付規格

用途：Windows 透明桌面寵物、Android 懸浮桌寵。第一階段以全身立繪、小幅即時反應為主：待機眼睛追鼠標、眨眼呼吸、依點擊位置做不同動作。美術品質為最高優先，先做少量精緻動作。

這是一份可直接交給繪師與建模師的規格。互動表是初稿，實際動作範圍應依畫稿可動性確認，不要求用拉伸硬做沒畫出的姿勢。

## 造型不可遺失的特徵

- 銀白偏淡藍的頭髮，後髮只到腰身；保留原本指定移除左側多餘髮束的修改。
- 淡藍眼睛，保持淺色，不做成深飽和藍。
- 黑色帽子；髮飾是 **五角星**，胸前緞帶飾是 **四角星**，不可混淆。
- **黑色披肩、白色袖套、上臂露出**；袖套不是連到肩膀的白長袖。
- 披肩和髮飾沒有多餘垂吊吊飾；不要自行增加。
- 鞋為很深的棕色皮革，乾淨、低調正常反光，不要碎光、亮片或星點。
- 本次立繪不持法杖。
- 眼睛、星飾、布料圖案與皮鞋在變形時仍保持線條形狀、材質及原色。

既有參考：[`../argon-reference-v5/`](../argon-reference-v5/)，早期版本僅作比較；正式繪製前以使用者指定的最新定稿為準，不能只依版本號猜造型。既有圖皆是合成 PNG（1024×1536），不是已拆好的模型原稿。

## 原稿要求

- 交付原生分層 PSD，RGB、透明背景；保留色彩描述／工作色域說明，避免不明轉色。若同時交 PNG，使用含 alpha 的無損 PNG。
- 新繪製全身稿可先以約 **3000–5000 px 高**估畫布與工作量，這是建議而非強制縮放規格；依實際顯示尺寸、可放大程度及繪師原生細節確認。現有 1536 px 高 PNG 插值放大不算新高解析原稿。
- 保留完整分層母稿。匯出圖層使用同一原尺寸畫布、原點與相對位置，不分別裁到不同尺寸後遺失對齊資訊；建模師若使用裁切圖層，需保留可重建的偏移資料。
- 不裁掉頭頂、後髮、鞋底；畫布留足動作範圍。不要在人物上合併背景、陰影底圖、說明文字或浮水印。
- 部件命名清楚，`L/R` 一律依 **角色自身左／右**。線稿、上色、陰影是否合層可由建模師決定，但不同可動部件不可合成一張。
- 轉頭、抬手、晃髮後會露出的地方要補畫，不使用透明洞、延伸抹色或過度拉伸來掩蓋。

## 建議拆圖

| 部位 | 最低拆分／補畫需求 |
| --- | --- |
| 頭與臉 | 臉底含被髮遮住的輪廓；耳朵分左右；臉紅／陰影依表情需求分層。 |
| 每隻眼睛 | 眼白、虹膜／瞳孔、眼睛高光、上眼皮／睫毛、下眼皮；補足轉動時的眼白，閉眼線需可控。高光可以隨瞳孔，但不能固定在原地露到眼框外。 |
| 眉毛 | 左右分開，足夠偏移／表情空間。 |
| 嘴 | 嘴線、口腔、需要的唇／牙／舌；先做微笑／驚訝即可，錄音嘴形可之後加。 |
| 頭髮 | 瀏海、兩側髮、後髮及可獨立晃動的髮束；後髮長度保持到腰，補齊底下的頭／頸／衣服。 |
| 帽、髮飾與蝴蝶結 | 與髮分離，五角星不得拉成不規則形狀；不加垂吊配件。 |
| 頸與軀幹 | 頸、衣領、上身；把頭與披肩移開時仍沒有空洞。 |
| 黑披肩 | 可動前片／側片／後片依需要拆分，金邊與星圖附著在布面，晃動時不游離或扭爛。 |
| 手臂與白袖套 | 露出的上臂、前臂、白袖套、袖口、手掌各自可控；左右分開，補畫袖口遮住的手臂。 |
| 手勢 | 最少原始待機手型；要揮手時另畫所需手型／手指，不硬拉原手掌。 |
| 胸前緞帶與四角星 | 與披肩／軀幹合理分層，四角星維持形狀。 |
| 腰帶與裙子 | 前後裙／側片依重心動作拆分；補畫裙擺下腿部，避免露出透明洞。 |
| 腿與鞋 | 左右腿、腳踝、深棕鞋分層；若腳尖要抬起，補畫鞋面與腳踝角度需要的區域。皮革反光乾淨。 |

不要求第一版大幅轉身或背面；要新增大角度時先補繪相應視角。小幅頭部 XY 也需檢查斜角組合，不能只交正左／正右／正上／正下四個方向。

## 綁定與參數

建議採標準參數名稱；如使用自訂 ID，附對照表即可。參數數值範圍以實際模型為準，程式不得假設所有模型一致。

| 參數 | 要能做到的效果 | 階段 |
| --- | --- | --- |
| `ParamEyeBallX`、`ParamEyeBallY` | 左右眼共同看向目標；四角不露縫、不鬥雞眼 | 必需 |
| `ParamEyeLOpen`、`ParamEyeROpen` | 自然睜閉與眨眼；閉眼時瞳孔／高光不穿出 | 必需 |
| `ParamBreath` 或等價 ID | 輕微呼吸，避免整張圖等比放大縮小 | 必需 |
| `ParamAngleX/Y` | 小幅轉頭，初步可先以約左右 10–15°、上下 5–10°的觀感製作，不強行拉滿標準 ±30 範圍 | 建議 |
| `ParamAngleZ`、`ParamBodyAngleX` | 小幅歪頭與重心反應 | 建議 |
| 嘴形／嘴開合、眉毛、手臂與腳部自訂 ID | 依反應動作需求，附範圍、預設值和正負方向 | 按動作 |

髮絲、蝴蝶結、袖口與披肩可加物理，幅度克制；不能把五角星／四角星、金邊或鞋面反光當成需要亂抖的特效。回正不永久抖動，不穿過臉或手臂。

## 動作與點擊區域

最小可用模型先交：一個待機、頭部反應、臉頰反應、手部反應。建議動作如下：

| 動作群組建議 | 動作 | 追視處理 |
| --- | --- | --- |
| `Idle` | 呼吸、小幅重心／髮絲；眨眼可由程式控制 | 不持續覆寫眼球 XY |
| `TapHead` | 輕低頭、眨眼後柔和回正 | 依動作降低頭部追隨，眼球可保留或短暫接管 |
| `TapCheekL/R` | 被點側輕偏頭、短促驚訝再微笑 | 避免眼球目標與動作互相拉扯 |
| `TapHandL/R` | 對應手小抬／招呼，袖口回彈 | 可繼續追視 |
| `TapCape` | 肩膀輕縮、披肩輕晃 | 後續擴充 |
| `TapShoes` | 小幅腳尖／重心回應 | 後續擴充，先檢查裙／腿遮擋 |
| `TapDefault` | 一般短回應 | 可共用已完成動作 |

提供隨模型變形的命中網格／可對應 Drawable ID：`Head`、`CheekL/R`、`HandL/R`，後續可加 `Cape`、`Shoes`。這些名字是交付約定，實際 ID 在 `delivery.json` 寫清楚。命中區域不只是畫在另一張 PNG 上的固定矩形；要隨轉頭與抬手移動。程式仍會檢查可見 alpha 與遮擋。

動作是可打斷、可從 0 重啟的短回應，不依賴把一串動作播完才能回待機。交代動作的長度、接管參數、開始／結束姿勢與淡入淡出建議。表情可交 `.exp3.json`，不要只燒錄在展示影片中。

## 交付檔案

1. **原稿**：分層 `.psd`，必要的原尺寸透明圖層、定稿參考及補畫說明。
2. **可編輯工程**：Cubism `.cmo3`；使用動畫時間軸時附 `.can3` 與關聯檔。記錄 Editor 版本與匯出設定。
3. **執行模型包**：主 `.model3.json`、其 `.moc3`、全部原尺寸 PNG 貼圖集、`.physics3.json`；另附引用到的 `.motion3.json`、`.exp3.json`、`.pose3.json`／`.cdi3.json`／userdata 等。不是所有輔助檔都必須存在，但凡主檔引用的都不能缺。
4. **參數與互動表**：ID、範圍、方向、命中 Drawable、動作群組、動作接管的參數和物理輸入。可複製 `delivery.example.json` 填寫。
5. **驗收資料**：原生清晰截圖與檢查影片，包括正中、四角追視、閉眼、各部位反應、連續切換與物理回正。
6. **權利說明**：可供 Anzuki Windows／Android 桌寵使用、發行、公開 GitHub 原稿／模型工程／模型包，並允許後續修改；列明作者署名方式。若有第三方素材須另列其範圍與條款。

貼圖用無損 PNG，不使用 JPEG／有損 WebP 或會降低品質的 GPU 貼圖壓縮。貼圖集保持足夠原生 texel 密度；若模型輸出工具縮放了原稿，必須記錄比例並先做美術驗收，不能自動降質。手機不另做低畫質包，先以同一模型／貼圖測試記憶體與 GPU 上限。

目前不要求繪師提供音聲、攝影機追蹤資料或新影片。既有 MP4／WebP 可作動作參考並原樣保留；之後要配音時使用使用者提供的錄音。
