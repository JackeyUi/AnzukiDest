# Anzuki ボイス収録台本 v1 — 日本語版

[繁體中文版](RECORDING-SCRIPT.md) · [セリフ一覧（テキスト版）](RECORDING-LINES.ja.txt)

全24本：曜日別の朝のあいさつ7本、時間帯別のあいさつ5本、時間帯別のクリック反応5本、曜日別の待機中のひとこと7本。よく使うものから収録して大丈夫です。

## 話し方・収録の目安

- やわらかく自然な声で、少しだけはにかむように。隣でそっと寄り添う雰囲気にしてください。
- 声を無理に高くせず、息を混ぜすぎない、聞き取りやすい発音でお願いします。一人称は「私」です。
- 読み上げるのは「セリフ」欄だけです。見出し、ファイル名、再生条件は読み上げません。
- 「、」「。」では自然に間を取り、頭と末尾にそれぞれ約0.2秒の余白を残してください。
- 元のWAVまたはFLACを推奨します。MP3、OGG、M4A、AACも取り込めます。アプリは音声を再圧縮したり、アニメーションの倍速に合わせて早回ししたりしません。

## 再生されるタイミング

時刻と曜日は、端末に設定されたローカルタイムゾーンで判定します。曜日はその端末の午前0時に切り替わります。**端末の時刻が基準で、日本時間に固定されているわけではありません。**

| 時間帯 | 再生対象になる時刻 |
| --- | --- |
| 朝 | 05:00以上、11:00未満 |
| 昼 | 11:00以上、14:00未満 |
| 午後 | 14:00以上、18:00未満 |
| 夜 | 18:00以上、22:00未満 |
| 深夜 | 22:00以上、翌日05:00未満 |

朝の起動時は、その曜日専用のあいさつを優先します。対応する音声がまだない場合のみ、同じ時間帯の共通あいさつを使います。朝以外の起動時は、その時間帯の共通あいさつを使います。

クリック反応は現在の時間帯、待機中のひとことは現在の曜日に合うものを選びます。合う音声がない場合は何も再生せず、別の曜日や時間帯の音声では代用しません。手動の試聴では、曜日や時刻に関係なく任意の音声を確認できます。

## ファイル名について

下表の名前で保存してください。拡張子はWAVを例にしています。別テイクは `greeting-mon-morning__take2.wav` のように名前を付けられます。取り込み時に対応するセリフを指定すれば、元のファイル名のままでも使えます。

日本語版も既存の24個のファイル名をそのまま使います。日本語の録音を対応するセリフに割り当てられるので、言語用の接尾辞を付ける必要はありません。

## アプリの音声設定

待機中の自動おしゃべりは初期状態ではオフです。設定でオンにすると、1〜10分の間隔を選べます。連続クリックには2.5秒のクールダウンがあり、音声は重ねて再生しません。ミュート中や音声音量が0のときは再生しません。Androidの自動再生は、端末のサイレント設定や他のメディア再生中にも配慮します。

1ファイルは50 MBまで、各カテゴリは12ファイルまで取り込めます。取り込んだ個人の音声はその端末内に保存され、選択や試聴によって自動アップロードされることはありません。
