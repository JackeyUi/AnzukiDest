# Anzuki 音聲文本 v1

[日本語版](RECORDING-SCRIPT.ja.md) · [日文台詞純文字版](RECORDING-LINES.ja.txt)

共 24 句：7 句星期早安、5 句時段招呼、5 句時段點擊、7 句星期閒聊。你可以先做最常用的幾句，不必一次錄完。

角色口吻：輕柔、自然、略微靦腆，像在身旁陪伴。少量氣音即可，字音清楚，不刻意拉高音調。每個檔案只念「台詞」欄，不念檔名或使用條件。句間自然停頓，頭尾可各留約 0.2 秒空白。

建議交付原始 WAV 或 FLAC；已有的 MP3、OGG、M4A、AAC 也能匯入。程式不會重新壓縮、變調或把聲音跟著動畫倍速播放。

時間依各裝置的本機時區，星期在當地午夜切換。早晨 05:00–10:59；午間 11:00–13:59；午後 14:00–17:59；晚間 18:00–21:59；深夜 22:00–翌日 04:59。時段終點不包含在內。

啟動時優先使用「當天星期早安」；該句尚未匯入時，才使用同時段通用招呼。其他時段使用對應通用招呼。點擊只選當前時段；待機閒聊只選當天星期。沒有適用音檔時保持安靜，不拿其他星期或時段的檔案代替。試聽可手動播放任一句。

把音檔依下表命名，例如 `greeting-mon-morning.wav`。同一句若有不同錄法，可命名 `greeting-mon-morning__take2.wav`。匯入時也可直接指定台詞，無須改原檔名。
