## 角色特徵

- 銀白色後髮長度到腰身。
- 髮飾是藍色五角星；胸前黑色緞帶的星飾是藍色四角星。
- 眼睛為較淡、低飽和度的藍色。
- 黑色短披肩與髮飾沒有垂吊鏈條、水晶或吊墜；腰部懷錶與鏈條保留。
- 白色寬袖是獨立袖套，與披肩之間露出上臂皮膚。
- 鞋面是乾淨、平滑的黑色皮革，採柔和反光，沒有碎光或玻璃切面。
- 雙手空著，沒有法杖。
